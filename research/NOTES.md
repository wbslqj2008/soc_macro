- 프로세스명 `SoC`, 창 제목 "소드 오브 콘발라리아". 창 위치는 실행마다 달라짐(모니터 무관하게 ClientToScreen으로 처리).

  타일 중심 = (bar_x + 13, bar_y + 118). d1(6/6), e8(5/5) 검출 정확. 적은 빨간 바라 제외됨. (`allies.py` 프로토타입)

  누름 유지 0.5초 이하는 드래그로 인식 안 됨.

## 구현 중 알게 된 것 (실제 테스트 기반)
- **OCR 기울기 오판**: 쿼터뷰 바닥의 2:1 사선(≈26.6°) 때문에 Windows OCR이 TextAngle≈26°로 deskew하고 글자를 거의 못 읽음.
  → 기울기 3° 초과 시 높이 150(겹침 30)의 가로 띠로 나눠 재인식. 작은 기울기(±3°)는 좌표를 TextAngle만큼 되돌려 회전.
- 전투 HUD의 "수동/가속" 작은 글자는 OCR이 자주 놓침 → 템플릿(hud_speed / hud_manual / hud_auto)으로 판정. 전투 ≈1.0, 비전투 ≤0.35.
- 맵 끝에서 "VoD 5-7" 라벨이 보스/상자 아이콘과 합쳐져 OCR 실패 → 라벨 줄(y≈282/372/462)만 따로 OCR.
- 전투에서 나오면 맵 스크롤 위치가 유지되어 다음 노드가 화면 밖일 수 있음 → 보이는 라벨 번호로 방향 판단 후 드래그(짧게 누름 0.1초)로 스크롤.
- 승리 화면은 첫 클릭에 안 넘어갈 때가 있음 (중복 처리 방지 필요).
- 게임 창은 자유롭게 리사이즈 가능하며 UI가 비율대로 커짐. 1274x717, 1920x1080, 1600x900에서 한 판 완주 확인 (1600x900에서 패배→배치 교체→재도전 승리, 아군 5/5 검출).
- PrintWindow(PW_RENDERFULLCONTENT)로 가려진 상태에서도 캡처 가능.
- 배치 교체: 독립 무작위 쌍은 서로 상쇄될 수 있음(A↔B 후 B↔A) → 섞은 뒤 겹치지 않는 쌍만 교체.

## 일일퀘스트 (엇갈린 세계) — 2026-11-02 조사, 스크린샷 `screens/daily/`
- 경로: 로비 우하단 "출항" → "엇갈린 세계"(왼쪽 카드) → 상단 탭 "일일 이벤트"(기본 선택).
- 카드 목록은 가로 캐러셀: 타로의 자취, 장비 시련, 기억 회복, 실전 훈련, 진급 시련, 뭇별의 시련, 제작 시련, (정복의 탑, 개척…).
  드래그로 스크롤. 카드 상단에 "남은 횟수 N"(장비/기억) 또는 "고급 보상 N" 표시.
- 하위 선택이 있는 컨텐츠:
  - 타로의 자취 1~5 (요일 잠금: 2 화/금, 3 수/토, 5 화/목/토, 일요일 전부. 1·4는 월요일에 열림)
  - 장비 시련 1~3 (2 화/금, 3 수/토, 일요일 전부). 남은 횟수 1/일.
  - 진급 시련: 수호자/침입자/파멸자/분쇄자/감시자 시련 (잠금 없음)
  - 뭇별의 시련 1~3 (잠금 없음, "일요일에는 모든 시련에 고급 보상")
- 바로 스테이지 맵인 컨텐츠: 실전 훈련(소탕 20), 제작 시련(소탕 30), 기억 회복.
- 스테이지 맵: 들어가면 마지막 클리어 스테이지가 선택되고 오른쪽 패널이 열림. 소탕(≈920,627) / 출격(≈1135,627). 비용은 패널 버튼에 표시.
  뒤로가기 1회 = 패널 닫기, 2회 = 이전 화면.
- 소탕 팝업: "문어 통조림 사용"(즉시 → 획득 정보) / "계속 소탕"(캐릭터 자동 선택 → 우하단 확인 → "○○ 시련 완료" 보상 → 화살표). 횟수 선택 n/최대.
- 로비 "출항" 글자와 출항 선택 화면의 카드 제목은 OCR 불가(장식 글꼴) → 로비는 "이벤트" 버튼으로 판별 후 출항 좌표(1060,655) 클릭, 출항 화면은 템플릿 `sail_crossed_world`.
- 로비에서 좌상단(뒤로가기 위치) 클릭 = 프로필 열림. 로비에서는 뒤로가기 금지.
- 소탕 팝업의 "계속 소탕" 버튼은 전체 OCR에서 누락됨 → 팝업은 "소탕횟수선택"/"즉시완료"로 판별. 계속 소탕 버튼(713,483), 캐릭터 선택 확인(985,650).
- 하위 카드 잠금: 라벨 위 (CX±130, CY-120, h60) 띠를 따로 OCR해 '요'/'오픈' 포함 여부로 판정.
- 컨텐츠 페이지 우상단 "남은 횟수 0/1"(장비/기억)로 오늘 완료 여부 판정.
- 테스트(월): 실전 훈련·진급(수호자) 계속 소탕 성공, 장비/기억 남은 횟수 0 건너뜀, 타로2 잠김 알림 확인.
- 기억 회복 패널(남은 횟수 있을 때)은 "출격" 버튼 하나가 가운데(≈990,627)에 있음 → 출격은 영역(830,600,420,55)에서 글자로 찾아 클릭.
- 2026-11-03 전체 테스트: 7개 컨텐츠 문어 통조림 소탕 6개 + 기억 회복 전투 승리, 글로리 전장 쉬움 5회 완료.

## 저해상도(800x450) 대응 (2026-11-05, 배포 사용자 로그)
- 증상: 탐험 메인을 알 수 없는 화면으로 판단, 이벤트 목록에서 탐험의 여정 탭을 못 찾음. 로그에 "탐험 레벨"이 "탐혐 레벨"로 찍힘.

- 탐험 메인 판정에 제목 없이도 "보급소 + 탐험코인/정산기록/탐험레벨" 조합 허용. 이벤트 탭은 "여정!"으로도 찾음.

- 화면 폭 1200 미만이면 1280x720 이상 권장 알림.
- 실제 800x450 게임 화면은 직접 확보 못 함(합성 축소 이미지로만 검증). 로딩 중 창 크기 변경 시 게임이 종료된 적 있음.
